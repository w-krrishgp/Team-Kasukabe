# Smart Farm Intelligence Platform

An intelligent AgriTech frontend prototype built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**, designed specifically for hackathon demonstration.

> **From crop diagnosis → resource intelligence → financial empowerment → fair market access**

---

## 🌾 The Farmer Journey
```
DIAGNOSE  ───►  PLAN  ───►  FINANCE  ───►  PROTECT  ───►  SELL FAIRLY
```

---

## 🚀 Key Modules & Routes

| Route | Module | Purpose |
|---|---|---|
| [`/`](http://localhost:3000) | **Landing Page** | Value proposition, 5-stage visual journey, 4 feature cards & connected architecture |
| [`/dashboard`](http://localhost:3000/dashboard) | **Farmer Dashboard** | Health Overview (82%), Today's 4 Smart Actions, Connected Journey, Profile Card & 6 Quick Actions |
| [`/crop-doctor`](http://localhost:3000/crop-doctor) | **Crop Doctor** | AI pathology leaf scanner, yellow rust diagnosis, severity metrics & fungicide prescription |
| [`/farm-intelligence`](http://localhost:3000/farm-intelligence) | **Farm Intelligence** | 5-day weather & spray window advisory, soil moisture/NPK/pH telemetry, and fungal microclimate index |
| [`/finance`](http://localhost:3000/finance) | **Financial Empowerment** | 78/100 Health Score, PM-KISAN tracking, SMAM 50% mechanization subsidy, 4% KCC subvention |
| [`/market`](http://localhost:3000/market) | **Fair Market Access** | Live Mandi price comparisons (Meerut, Hapur, Ghaziabad vs. MSP), net revenue estimator for 90 Qtl harvest |
| [`/storage`](http://localhost:3000/storage) | **Storage & Pooling** | Certified e-NWR warehouse locator, pledge receipt financing, and interactive collective FPO crop pooling |

## 💻 Running Locally

To run the Next.js dev server:

```bash
cd frontend
npm run dev
```

Or from the root directory:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
